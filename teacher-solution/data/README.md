# Auto MPG source data

`mpg.csv` is the complete CSV from [seaborn-data](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/mpg.csv): 398 records and nine columns. It was retrieved through the web tool because direct downloads from local Python were refused. The numbered web-view prefixes were removed; CSV values and row order were retained. The local copy supports offline execution of the teacher solution.

The solution uses only the five inputs and target specified in the handout. No records or values were fabricated.
